# Security policy

## Supported versions

Security fixes are released for the latest minor version of `@erankushpatil/anky-ui` and the `anky-ui` CLI.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/ErAnkushPatil/anky-ui/security/advisories/new). Do not open a public issue.

Include the affected version, a description of the issue and steps to reproduce it. You should get a reply within a few days. Once a fix is released, the advisory will be published with credit to you, unless you prefer otherwise.

## Scope

- The React components and utilities in `packages/core`.
- The `anky-ui` CLI, which copies files into your project and may run your package manager.

Your own model endpoint, API keys and how you render accepted AI output are outside the library's control. The README's Security section explains how to handle them.
